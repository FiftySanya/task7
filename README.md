## Завдання 1: Передача виводу `who` до `more`

### Опис
Програма передає вивід команди `who`, яка показує користувачів, залогінених на машинах у мережі, до утиліти `more` для посторінкового перегляду.

### Результати
```
root ttyv0 Apr 30 19:07
root pts/0 Apr 30 19:08 (desktop-i0nq9nj)
--More--(END)
```

### Пояснення
- Використовується `popen()` для запуску `who` і зчитування її виводу.
- Другий виклик `popen()` запускає `more` і передає до нього вивід `who` рядок за рядком.
- Це дозволяє користувачу переглядати список активних сесій посторінково.

### Висновки
- Інтеграція зовнішніх команд через `popen()` є простим способом обробки їхнього виводу в програмах на C.

## Завдання 2: Імітація `ls -l`

### Опис
Програма відтворює функціональність команди `ls -l`, виводячи детальну інформацію про файли в поточному каталозі, включаючи права доступу, власника, групу, розмір і час останньої модифікації.

### Результати
```
total 32
-rw-r--r--  1 root wheel   506 Apr 30 20:03 task1.c
-rwxr-xr-x  1 root wheel  8888 Apr 30 19:56 task1
-rw-r--r--  1 root wheel  2064 Apr 30 20:35 task2.c
-rwxr-xr-x  1 root wheel 11264 Apr 30 20:35 task2
-rw-r--r--  1 root wheel     0 Apr 30 20:35 task3.c
```

### Пояснення
- Функції `opendir()` і `readdir()` використовуються для перебору вмісту каталогу.
- `stat()` отримує метадані файлів, такі як права доступу, розмір і час.
- Інформація про власника і групу витягується через `getpwuid()` і `getgrgid()`.

### Висновки
- Програма показує, як системні виклики дозволяють отримати і відобразити детальну інформацію про файлову систему.

## Завдання 3: Проста версія `grep`

### Опис
Програма шукає і виводить рядки у файлі, які містять задане слово, імітуючи базову поведінку команди `grep`.

### Результати
```
./task3 freebsd text.txt
freebsd grep command
```

### Пояснення
- Програма приймає два аргументи: слово для пошуку (`freebsd`) і файл (`text.txt`).
- Використовує `fgets()` для зчитування файлу рядок за рядком і `strstr()` для пошуку слова.
- Знайдені рядки виводяться на екран.

### Висновки
- Реалізація простого пошуку тексту демонструє базові операції з файлами та рядками.

## Завдання 4: Спрощена версія `more`

### Опис
Програма виводить вміст одного або кількох файлів посторінково, зупиняючись кожні 20 рядків для очікування вводу користувача.

### Результати
```
./task4 task4.c task3.c
#include <stdio.h>

int main(int argc, char* argv[]) {
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <file1> [file2 ...]\n", argv[0]);
        return 1;
    }

    int line_count = 0;
    for (int i = 1; i < argc; i++) {
        FILE* fp = fopen(argv[i], "r");
        if (!fp) {
            perror("fopen");
            continue;
        }

        char buffer[1024];
        while (fgets(buffer, sizeof(buffer), fp)) {
            printf("%s", buffer);
            line_count++;
-- Натисніть Enter для продовження --

            if (line_count % 20 == 0) {
                printf("-- Натисніть Enter для продовження --\n");
                getchar();
            }
        }
        fclose(fp);
    }

    return 0;
}
#include <stdio.h>
#include <string.h>

int main(int argc, char* argv[]) {
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <word> <file>\n", argv[0]);
        return 1;
    }

    const char* word = argv[1];
-- Натисніть Enter для продовження --
```

### Пояснення
- Програма обробляє файли, передані як аргументи, відкриваючи їх через `fopen()`.
- Рядки зчитуються за допомогою `fgets()` і виводяться через `printf()`.
- Кожні 20 рядків програма зупиняється, виводячи повідомлення і чекаючи `Enter` через `getchar()`.

### Висновки
- Посторінковий вивід дозволяє зручно переглядати великі файли, демонструючи контроль над виводом.

### Результати

./task4.c

### Пояснення

- Для підкаталогів викликає себе, додаючи їхній вміст до списку.
- Шляхи формуються і виводяться для кожного файлу.

### Висновки
- Рекурсія є потужним інструментом для роботи з ієрархічними структурами, такими як файлові системи.

## Завдання 7: Надання дозволу на читання для файлів `.c`

### Опис
Програма шукає файли `.c` у поточному каталозі, що належать користувачу, і пропонує надати дозвіл на читання іншим користувачам.

### Результати
```
Файл: task1.c
Права доступу: -rw-r-----
Власник: root
Група: wheel
Розмір: 506 байт
Надати іншим дозвіл на читання? (y/n): y
Права доступу оновлено.
Нові права доступу: -rw-r--r--

Файл: task2.c
Права доступу: -rw-r--r--
Власник: root
Група: wheel
Розмір: 2064 байт
Дозвіл на читання для інших уже встановлено.

Файл: task3.c
Права доступу: -rw-r--r--
Власник: root
Група: wheel
Розмір: 573 байт
Дозвіл на читання для інших уже встановлено.
```

### Пояснення
- Програма перевіряє файли `.c` за допомогою `readdir()` і `stat()`.
- Якщо файл належить користувачу, виводить його метадані і запитує дозвіл.
- При згоді викликає `chmod()` для додавання права `S_IROTH`.

### Висновки
- Інтерактивне управління правами доступу показує практичне застосування системних викликів.

## Завдання 8: Інтерактивне видалення файлів

### Опис
Програма дозволяє користувачу видаляти файли в заданому каталозі, пропонуючи вибір між масовим і поелементним видаленням.

### Результати
```

### Пояснення

- Видалення виконується через `unlink()`.

### Висновки

## Завдання 10: Генерація випадкових чисел

### Опис
Програма генерує випадкові числа з плаваючою комою в діапазонах [0.0, 1.0) і [0.0, n).

### Результати
```
Випадкові числа від 0.0 до 1.0:
0.978392
0.991206
0.354113
0.211472
0.821370
Випадкові числа від 0.0 до 10.000000:
3.632229
9.726495
3.682044
5.798531
3.780965
```

### Пояснення
- `srand48(time(NULL))` ініціалізує генератор.
- `drand48()` генерує числа в [0.0, 1.0), які масштабуються для другого діапазону.

### Висновки
- Генерація випадкових чисел корисна для тестування і симуляцій.

## Завдання 11: Виведення груп користувача

### Опис
Програма виводить первинну групу користувача та список його додаткових груп із членами.

### Результати
```
Первинна група: wheel
Групи користувача:
  Група: wheel
    Члени: root fs
  Група: operator
    Члени: root
```

### Пояснення
- `getuid()` і `getpwuid()` отримують інформацію про користувача.
- `getgrouplist()` витягує список груп.
- `getgrgid()` визначає членів кожної групи.

### Висновки
- Програма демонструє управління групами користувачів і доступом.
